# Security Policy

**Please do not report vulnerabilities in public issues, pull requests or discussions.**

Report them privately: open the **Security** tab of this repository → **Report a vulnerability**
(GitHub private vulnerability reporting). Only the maintainer sees the report. Include what is
affected, how to reproduce it and what an attacker could do.

---

**Пожалуйста, не сообщайте об уязвимостях в публичных issue, pull request или обсуждениях.**

Сообщите закрыто: вкладка **Security** этого репозитория → **Report a vulnerability**. Отчёт видит
только владелец. Опишите, что затронуто, как воспроизвести и что может сделать злоумышленник.
