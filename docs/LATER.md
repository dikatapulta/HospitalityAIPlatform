# LATER.md — потом: мелкие находки

> **Роль:** место для всего, что merge не блокирует (правило 9
> [PROJECT_EXECUTION_PLAN.md](../PROJECT_EXECUTION_PLAN.md), режим пилота — решение основателя
> 15.10.2026): мелкие дефекты, пробелы тестов вне критических путей, размеры файлов и функций,
> расхождения документов, формулировки и косметика, улучшения, правки процесса (правило 11),
> крайние случаи гипотетических сценариев. Серьёзное сюда не пишут — это блокер или issue.
>
> **Когда разбирать** — решает основатель (например, неделя долгов после запуска пилота). Сессия
> сама строки отсюда в работу не берёт: порядок работ — только [QUEUE.md](QUEUE.md) (правило 10).

## Как вписывать

Одна находка — одна строка, issue не заводится:

`- [ ] ДД.ММ — <откуда: ревью PR #N / окно задачи #N> — <что и где, одним-двумя предложениями>`

Вписывает тот же PR, где находка сделана: при вердикте changes requested — автор вместе с
доработкой, без блокеров — ревьюер коммитом в ветку PR до approve (правило 9). Сделанную строку
удаляет PR, который её сделал.
