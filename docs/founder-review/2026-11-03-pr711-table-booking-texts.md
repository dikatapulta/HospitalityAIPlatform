- [ ] **03.11.2026 — бронь столика: тексты гостю и персоналу и три решения (PR #711, #702, [spec 0064](../specs/0064-table-booking.md)): проверь решения.** Тексты (ru) — spec 0064 §5, показаны файлом диспетчеру до кода; en и kk — в теле PR 2 до кода. Решения сессии:
  - [ ] «Предложить другое время» не бронирует его: гость жмёт «Запросить на 20:30» — уходит новый запрос, ресторан подтверждает его одним нажатием. Иначе согласие гостя попадало бы в книгу броней без человека (spec 0064 §2.3).
  - [ ] Форма спрашивает «На чьё имя» (необязательно): имени гостя в системе нет — Opera отдаёт нам снимок без имён (ADR-004). Рекомендация в issue говорила «имя берём из проживания» — так не выйдет.
  - [ ] Гость отменяет подтверждённую бронь сам, кнопкой; ресторану уходит заявка «Гость отменил бронь — уберите из книги броней» (spec 0064 §2.4).
