- [ ] **03.11.2026 — 3D-витрина для групповых продаж (PR #801, #799, [spec 0069](../specs/0069-sales-showroom-3d.md), [ADR-025](../adr/ADR-025-public-showroom-without-login.md)): проверь решения окна и тексты.** Окно безголовое: показ текстов до кода ушёл диспетчеру файлом `ask/1-799-showroom-texts.md` (не блокирует). Код — после показа 05.11, с 06.11, так что любая правка здесь дешёвая.
  - [ ] **Тексты агенту и персоналу** — spec 0069 §5: подпись под моделью («Это схема здания, а не фотография… Наличие номеров и цены уточняет отдел продаж»), поле помощника и «Помощник отдыхает…», форма «Запрос в отдел продаж», строка согласия, «Это запрос, а не бронь…», «Запрос отправлен…», карточка «🏢 Групповой запрос #12 · …» и подсказка «Ответьте агенту по телефону или почте…», промпт помощника и образец ответа.
  - [ ] **Имя модуля `showroom`**, а не `showcase`: `tools/demo_showcase*` — скрипты демо к показу, два разных «showcase» в репозитории путали бы следующие окна. Глоссарий — «3D-витрина».
  - [ ] **Публичная страница без входа** — развилка с «строгим auth-only» (ADR-008 Q7, решение 22.07) закрыта ADR-025: разрешено для агентов (не гостей), модель только инструментом через своё назначение шлюза с бюджетом $1/день, лимиты по адресу, флаг `public_enabled` по письменному «да» отеля. Альтернатива «ссылка с токеном на агента» отложена «по сигналу».
  - [ ] **Модель помощника — Sonnet** (как ты хотел), не дешёвый тир GPT-4o mini из DISCUSSION_LOG: вызов ≈ $0,005, на $1 в день ≈ 200 вызовов, типовые фразы («этаж 15», «горы») разбирают правила без модели. Умолчание `LLM_MODEL_SHOWROOM` пустое — на dev и CI модели нет; на staging ставится модель гостя.
  - [ ] **Срок хранения контактов агентов — 365 дней** с создания запроса (обезличивание), а не 90 дней гостя: сделка по группе живёт месяцами. Число — моё; юристу вместе с политикой витрины (PR 5).
  - [ ] **Отдельная политика витрины** (`/legal/showroom-privacy`), а не раздел в политике гостевого чата: та начинается с «относится к чат-сервису отеля» и перечисляет данные гостя — агент читал бы чужой документ. В issue было «раздел политики»; смысл тот же, документ свой.
  - [ ] **Сцена — таблица `showroom_scenes`, не конфиг тенанта**: конфиг читается на каждом ходу гостя, а сцена на 350 номеров — десятки килобайт. Просмотрщик параметрический (прямоугольный корпус, этажи, номера по сторонам); здание другой формы — по сигналу второго отеля.
  - [ ] **Источник заявки `showroom_form` вне доли Exit-критерия** «≥ 70% без участия ресепшена» (spec 0035 §4): запрос агента — не заявка гостя, считать его в знаменатель значило бы занижать долю.
