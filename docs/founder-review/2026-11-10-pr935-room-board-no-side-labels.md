- [ ] **10.11.2026 — Доска «Номера» без подписей сторон коридора (PR #935, #905): проверь решение окна.** По твоему слову 10.11 («пусть не будет надписи вид на город вид на горы, а дальше сам реши как сделать») подписей «Вид на горы» / «Вид на город» больше нет нигде: ни слева от ряда, ни над плитками на телефоне, ни в панели номера — там «14 этаж». Выбрано: этаж остаётся двумя рядами по сторонам коридора, как на румплане, только без слов; между рядами сторон зазор вдвое шире, чем между клетками, — сторону видно и без подписи. Отвергнуто: один общий ряд на этаж — пропала бы раскладка румплана (#674), к которой у тебя замечаний не было, а не только надпись. Ключ стороны в профиле отеля остался — по нему доска делит этаж на ряды. Хочешь один ряд без деления — скажи: «в доске Номера — этаж одним рядом», это правка кода доски.
