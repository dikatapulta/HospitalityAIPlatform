- [ ] **10.11.2026 — подпись сотрудника: привязка устройства (PR #943, #936, [spec 0077](../specs/0077-staff-memos.md) §4, §9): проверь решения окна.** Слова основателя по этим пунктам нет; окно выбрало по своей рекомендации (#909). Экранов в этом PR нет — тексты появятся у сотрудников в PR 4 серии, поправить их до этого дёшево.
  - [ ] **Привязать устройство можно только во входе с «Запомнить меня».** Вход без галочки по spec 0073 — общий компьютер стойки; если разрешить привязку там, компьютер с общим ПИН-кодом Windows Hello станет «личным устройством» каждого, кто на нём входил, и лист подписей напишет неправду «подтверждено с личного устройства» (находка ревью PR #938). Отвергнуто — разрешить везде и только предупредить текстом: текст на стойке не читают. Цена: сотрудник, вошедший на своём телефоне без галочки, выйдет и войдёт заново; подписывать паролем он может и так.
  - [ ] **Новые тексты сотрудникам** (spec 0077 §9): над кнопкой привязки — «Только свой телефон — не компьютер стойки.»; вход без галочки — «Привязать можно только своё устройство. Войдите на нём с галочкой „Запомнить меня“ — или подписывайте паролем кабинета.»; заголовок пуша — «Привязано устройство для подписи»; кнопки плашки — «Это я» и «Это не я». Вариант короче отвергнут: без «или подписывайте паролем» сотрудник решит, что подписывать ему нельзя вовсе.
  - [ ] **«Это не я» гасит не только ключ, но и вход, которым его привязали.** Тот, кто привязал чужой ключ, знает пароль; погашенный вход его выгоняет, а дальше сотрудник меняет пароль (текст плашки). Если плашку нажал сам владелец, забывший про свой телефон, — телефон просто попросит войти снова. Плашку не видит и не закрывает тот вход, который ключ привязал: иначе чужой убрал бы предупреждение сам.
  - [ ] **В ключ на телефоне уходит только логин, без имени.** Телефон хранит при ключе подпись «для кого он»; у ключей iPhone и Android она синхронизируется в облако Apple или Google самого сотрудника. Логина хватает, чтобы сотрудник узнал свой ключ; имя туда не отправляется (строка в PII_REGISTRY).
  - [ ] **Менеджер может «Сбросить подпись» и себе** — это не потеря доступа, в отличие от отключения себя.
