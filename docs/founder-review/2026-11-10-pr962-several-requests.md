- [ ] **10.11.2026 — несколько просьб в одном сообщении гостя (#90, PR #962, [spec 0078](../specs/0078-several-requests-in-one-message.md)): проверь решения окна.** Показано файлом через диспетчера, он принял вариант окна по рекомендации (слово основателя 10.11, #909). Поправить — правило в `ai/prompts/concierge_v9.md`, раздел `# Service requests`, или §2 спеки.
  - [ ] Каждая просьба — своя заявка; вопросы про все — одним сообщением, строка за строкой; одно «да» оформляет все. Образец: «убери номер, принеси полотенца и 2 пачки кофе» → «Кофе через меня заказать не получится — с этим поможет ресепшен. Оформить уборку номера 305? / Принести полотенца в номер 305?». Отвергнуто: по очереди (гостю три раунда «да» вместо одного) и одна заявка на службу (квота бесплатного и «выполнено частично» считаются по заявке — слитую не закрыть честно наполовину).
  - [ ] Ответ «только полотенца» бот не исполняет частью пакета, а переспрашивает одну выбранную просьбу: один лишний вопрос вместо новой ветки разбора ответа.
  - [ ] Для просьбы без подходящей службы бот не предлагает позвать сотрудника, а направляет на ресепшен: «да» гостя на такой реплике ушло бы подтверждению заявок, и обещанного сотрудника не позвал бы никто.
