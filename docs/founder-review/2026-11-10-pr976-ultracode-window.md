- [ ] **10.11.2026 — окно многоагентного режима у сторожа пула (PR #976, #959): проверь решения окна.**
  Окно шло по рекомендации консультанта из тела #959 (слово основателя 10.11, #909); что выбрано
  и почему:
  - [ ] **Пометка пункта** — `ultracode` вместо effort в метке модели: «**Opus 5.5 `ultracode`**»,
    «**Fable 5 `ultracode`**». Модель берётся из той же метки, отдельной разметки не нужно, а слово
    `ultracode` в прозе строки пометкой не считается. Отвергнуто: отдельная метка `[многоагентно]` —
    вторая разметка рядом с моделью, расходится с ней.
  - [ ] **Модель окна — модель пункта.** Аудит (класс Fable по правилу 7) идёт на Fable, многофайловая
    миграция — на Opus. Окно одно, новое не чаще раза в час — как окно Fable (тело #959).
  - [ ] **Запуск прогона разрешён окну флагом** `--allowedTools Workflow`, только этому виду окна.
    Без него запуск решал бы классификатор режима auto, а он не знает о пометке и может отказать —
    окно, пущенное ради прогона, ушло бы одиночкой. Действия агентов прогона классификатор
    проверяет как раньше.
  - [ ] **Лимит подписки — иначе, чем в теле #959.** В issue: «окно отчитывается в "Передаче"
    и уходит». На деле окно, упёршееся в лимит, сделать уже ничего не может, а сторож и сейчас
    через час возобновляет такое окно той же сессией. По документации Claude Code прогон в
    возобновлённой сессии перезапускается с сохранёнными результатами: теряется только работа
    агентов, упавших или шедших в момент лимита. Вживую не проверено — первый прогон покажет.
  - [ ] **Ревью PR пометкой не покрыто.** Пометка стоит на пункте раздела 1, а раздел 0 (открытые PR)
    ведёт GitHub, не файл. Ревью уровня A с миграцией или входом по-прежнему многоагентно, только
    если основатель сам наберёт слово в ручном окне. Захочешь и это — скажи, будет отдельный issue.
  - [ ] **Сделай: правку сторожа — в окне с тобой.** Классификатор безголового окна отказал в правке
    `ops/pool-spawn.sh` («Self-Modification»), как и предполагало тело #959. Готовый патч и промпт для
    окна — в комментарии «Передача» в #959; окно применит его, когда ты подтвердишь словами в чате.
