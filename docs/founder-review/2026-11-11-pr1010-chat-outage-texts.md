- [ ] **11.11.2026 — Что видит гость веб-чата, когда у отеля лежит база (PR #1010, #991): проверь решения окна.** Тексты показаны окну-диспетчеру файлом до кода, вопрос не блокировал работу.
  - [ ] **Тексты.** Под недоставленным сообщением (сервер ответил ошибкой 5xx или пропала сеть) к старой строке добавляется вторая: «Не доставлено, попробуйте ещё раз. Если срочно — позвоните на ресепшен (0 с телефона в номере) или подойдите к стойке.» Строка на языке гостя, «0» — из настройки отеля «что набрать с телефона в номере», без настройки фраза идёт без цифры. На экране входа по коду и на ссылке с листка вместо английского «Internal server error» — «Ошибка, попробуйте ещё раз» и та же фраза на трёх языках. Страница по QR, меню, столик и реквизиты при ошибке сервера показывают вместо JSON карточку на трёх языках: «Чат сейчас не работает, попробуйте позже. Если срочно — позвоните на ресепшен с телефона в номере или подойдите к стойке.» Слова взяты из текста ЧП, только «прямо сейчас» заменено на «если срочно»: сбой доставки — не всегда ЧП. Отвергнуто: только «позвоните на ресепшен» без «попробуйте ещё раз» — гость с обычной просьбой не узнал бы, что можно просто отправить снова. Хочешь иначе — скажи: «в тексте сбоя чата — <как>».
  - [ ] **Вес страницы чата.** По условию #746 страница новым видом не тяжелее прежней вдвое. Эти строки добавили 0,7 КБ, страница вышла за предел на 0,5 КБ (29,7 КБ из 29,2). Вынести тексты отдельным файлом нельзя: когда сервер не отвечает, этот файл тоже не загрузить. Решение окна — к пределу теста добавлен отдельный запас 1 КБ, только под эти тексты; правило «вид не тяжелее вдвое» не тронуто. На гостиничном Wi-Fi 1 КБ — меньше миллисекунды. Отвергнуто: сокращать текст, пока он не влезет, — гость при ЧП получил бы обрывок. Против запаса — скажи: «в весе чата — без запаса», тогда строку придётся сократить.
