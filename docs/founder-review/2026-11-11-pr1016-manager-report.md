- [ ] **11.11.2026 — «Отчёт» руководителю: состав листа и надписи (PR #1016, #950, [spec 0083](../specs/0083-manager-report.md)): проверь решения окна.** Показано через окно-диспетчера; ответ диспетчера 11.11 — «(а) — по рекомендации окна» (слово основателя 10.11, #909). Тексты — spec 0083 §4. Лист — черновик за выключателем: на staging включается сам, на копии отеля — по твоему слову.
  - [ ] Неделя и месяц — прошлые календарные (пн–вс, с 1-го по последнее число), а не «последние 7 дней»: на бумагу идёт законченный период, и сравнение честное — целая неделя с целой. Отвергнуто: скользящие 7 и 30 дней — сегодняшний неполный день сравнивался бы с полным.
  - [ ] Время — медиана, а не среднее (как в сводке дня): одна заявка, взятая через сутки, делает среднее бессмысленным.
  - [ ] «Выполнили за» — от заявки до «Готово» (сколько ждал гость), а не от «Взять»: руководству важно ожидание гостя; работу сотрудника по времени показывает «Статистика».
  - [ ] Только менеджер: на листе итоги экзамена по службам — данные о людях, как «Итоги экзаменов». Идеи — одним числом по отелю, без служб и имён: сотрудникам обещано «руководству — только общие выводы, без имён».
  - [ ] PDF делает браузер (кнопка открывает печать, там «Сохранить как PDF») — без новой библиотеки на сервере.
  - [ ] Свои даты — до 92 дней (квартал): дольше лист не нужен, а запрос остаётся быстрым. Вопросы гостей хранятся 90 дней — у периода старше на листе «—» с причиной, а не ложный ноль.
