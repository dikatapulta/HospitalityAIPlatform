- [ ] **11.11.2026 — справочник города Алматы для консьержа (PR #1018, #952, [spec 0085](../specs/0085-city-guide-almaty.md)): проверь решения окна.** Черновик за флагом: на staging включится сам, у гостей отеля — только по твоему слову. Как поменять — «скажи: в справочнике города — <как>».
  - [ ] **Как бот узнаёт о городе — блоком промпта, а не инструментом.** Бот видит весь справочник на каждом ходу, как справочник отеля. Отвергнут инструмент «найди в справочнике»: на каждый вопрос о городе — второй запрос к модели, а оркестратор ходит к ней за ход один раз; и его же сейчас может строить окно погоды и курса (#951) — две переделки одного места. Цена блока — в spec 0085 §4; на копии отеля включать после кэша промпта (#138).
  - [ ] **Записи — по-английски, местное имя в скобках** («Medeu ice rink (Медеу)»). Промпт бота английский, 70 % гостей иностранцы — перевод с английского на их языки надёжнее, а английский вдвое дешевле по токенам. Русское имя в скобках — показать таксисту. Отвергнут русский текст: справочник отеля по-русски уже тянул ответы англичанам на русский (spec 0036 §8.2).
  - [ ] **Ссылка на карту — Google Maps, без ключа.** Её строит код, бот переписывает дословно — выдуманного адреса гость не получит. Google — потому что иностранцы его знают и формат ссылки описан официально. Отвергнут 2ГИС: точнее по Алматы, но формат ссылки поиска не описан как стабильный; вернуться к нему — с портом карт (Phase 2).
  - [ ] **Город берётся из профиля отеля, а не из второй настройки.** Отель в Астане с ошибочной настройкой «Алматы» получил бы чужой справочник — неправда гостю. Справочника для города нет — бот о городе молчит, как сейчас.
  - [ ] **Содержимое — без цен, часов работы, экстренных номеров, ресторанов и отелей по имени.** Цены и часы меняются — бот советует сверить на ресепшене; экстренные службы вызывает ресепшен (твоё правило 19.08); заведения меняются и читались бы как реклама. Каждая запись — с источником и датой проверки 11.11.2026; прочесть файл — `src/hospitality/modules/concierge/data/almaty.toml`.
