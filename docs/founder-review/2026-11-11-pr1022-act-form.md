- [ ] **11.11.2026 — черновик АВР по кнопке бухгалтера (PR #1022, #953, [spec 0086](../specs/0086-work-completion-act-draft.md)): проверь решения окна.** Окно решило само по своей рекомендации (слово основателя 10.11, #909) и по правилу юрвопросов (#947).
  - [ ] **Какая форма акта** (Р-1): вопрос — по какой форме платформа собирает АВР. Норма — Закон РК «О бухгалтерском учете и финансовой отчетности» № 234-III, ст. 7 п. 2: формы первичных документов утверждает уполномоченный орган (редакция 21.10.2026, zakon.uchet.kz/rus/docs/Z070000234_); форма Р-1 «Акт выполненных работ (оказанных услуг)» — Приложение 50 к приказу Министра финансов РК от 20.12.2012 № 562, в редакции приказа № 458 от 27.10.2014; приказ — с изменениями на 28.03.2018, приложение 50 позже не менялось (zakon.uchet.kz/rus/docs/V1200008265, сверено 11.11.2026). Вывод — черновик повторяет все графы и подписи Р-1, подпись, печать и дату подписания ставят люди на бумаге; язык — русский, казахский вариант формы — `docs/later/`. Поменять — «в АВР — <как>».
  - [ ] **Срок хранения черновика** (Р-6): снимок несёт ПД заказчика-ИП (ФИО, ИИН, адрес) и обезличивается вместе с запросом реквизитов — тот же срок spec 0032; номер, дата и сумма остаются. Подписанный акт хранит отель в своём учёте (закон № 234-III ст. 11) — черновик платформы его архивом не считается. Отвергнуто: хранить черновик пять лет как первичный документ — у платформы был бы второй архив ПД без цели. Поменять — «в АВР — хранить черновики <срок>».
  - [ ] **Номер акта вписывает бухгалтер** (Р-3): нумерация актов живёт в 1С отеля, второй счётчик в платформе разошёлся бы с ней. Поменять — «в АВР — пусть платформа нумерует сама».
  - [ ] **Исполнитель — из настроек отеля** (Р-4): юрлицо отеля один раз вписывается в файл профиля при онбординге (`act_executor`), а не в каждый акт; без него кнопка отвечает «Реквизиты отеля для АВР не заданы». Поменять — «в АВР — исполнителя пусть вписывает бухгалтер в форме».
  - [ ] **PDF — библиотекой `fpdf2` со шрифтом под OFL** (Р-7, PR 3): своей вёрстки PDF не пишем; Excel собираем без библиотек, как файл для 1С. Поменять — «в АВР — PDF <как>».
  - [ ] **Тексты кабинета** (§4 спеки, код — PR 2): кнопка «Сформировать АВР» только у строки «Проверено»; в форме «Номер акта», «Дата составления», «Договор — необязательно», строки «Услуга / Дата оказания / Ед. / Кол-во / Цена, ₸ / Стоимость», «Итого: 45 000,00 ₸», подсказка «Услуги и суммы вписываете вы — из PMS ничего не берётся…»; первая строка заполнена: «Проживание, номер 512, 10.11–12.11.2026», «сутки», число ночей; под строкой — «АВР № 15 от 11.11.2026 · 45 000,00 ₸ · Айгуль» и ссылки «PDF», «Excel»; отказы — «Реквизиты изменились после проверки — нажмите «Проверено» и сформируйте акт заново» и «Реквизиты отеля для АВР не заданы — их вносит администратор платформы». Поменять — «в АВР — <текст> так: …».
