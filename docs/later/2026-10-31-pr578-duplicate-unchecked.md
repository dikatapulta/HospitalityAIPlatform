- [ ] 31.10 — ревью PR #578 — «Дубль — такая заявка уже есть» гасит сообщение гостю, но сервер не проверяет, что у комнаты есть другая открытая заявка: ошибочный «Дубль» (например, вторая просьба после уже выполненной первой) оставит гостя без ответа и без заявки.
