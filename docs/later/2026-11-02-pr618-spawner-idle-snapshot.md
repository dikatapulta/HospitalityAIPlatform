- [ ] 02.11 — окно-диспетчер — сторож ([ops/pool-spawn.sh](../../ops/pool-spawn.sh), строка с `snapshot work >"$WORKERS/.idle-$kind"`) снимает образец пула для метки «брать нечего» в момент **выхода** окна, а не в момент, когда окно читало очередь. Изменение между этими двумя моментами попадает в образец и уже не считается изменением. Живьём 02.11: окна Opus смотрели очередь, пока PR #616 был «на ревью», в 02:15 ревьюер вернул его на доработку, окна тут же вышли с «брать нечего», и доработку взяли только в 03:15, через час. Исправление — снимать образец при запуске окна и хранить его до выхода. Последствие — простой пула до часа (а без побочного изменения — до `IDLE_MAX_SEC`, 8 часов), данные не теряются.
