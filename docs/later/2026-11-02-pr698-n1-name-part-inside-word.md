- [ ] 02.11 — ревью PR #698 (Н-1) — политика пароля (`platform/staff_credentials._personal_parts`) ищет любую часть логина или имени от 3 знаков внутри пароля, поэтому у сотрудника «Али» отвергается фраза «специалист отеля 7», у «Ким» — «акимат на углу 5», хотя имени в ней нет. Текст ERR-AUTH-016 и совет рунбука ([errors.md](../runbooks/errors.md), «фраза из трёх-четырёх слов без имени») такой отказ не объясняют. Лечится сравнением с целыми словами пароля для частей короче ~5 знаков; вреда нет — сотрудник подбирает другой пароль.
