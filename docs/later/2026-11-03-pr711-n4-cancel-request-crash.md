- [ ] 03.11 — ревью PR #711, Н-4 — [spec 0064](../specs/0064-table-booking.md) §2.4: при отмене подтверждённой брони может случиться сбой между отметкой `cancelled_by_guest_at` и созданием заявки «уберите из книги броней». Тогда гость прочтёт «мы передали это ресторану», а ресторан ничего не узнает. По образцу Р-3 spec 0038: `cancel_request_id = uuid4()` писать вместе с отметкой, `create_request` идемпотентен, а повтор отмены или показ страницы доводит заявку. В §7 п. 5 добавить тест «сбой между отметкой и заявкой».
