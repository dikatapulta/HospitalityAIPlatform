- [ ] 03.11 — окно задачи #767 — раздел «Диалоги» ([spec 0067](../specs/0067-staff-conversations.md) §2.1) показывает только веб-чат: под каналом `telegram` в `conversations` рядом с гостевыми чатами лежат служебные чаты персонала (уведомления о заявках, `notifications.py`, `reminders.py`), и отличить их можно лишь по `TenantConfig.staff_chat_ids` — настройке, которая меняется.
