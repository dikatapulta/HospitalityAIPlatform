- [ ] 07.11 — ревью PR #867 — SQL-форма этажа (`shared/rooms.py`, `floor_of_room_sql`) снимает по краям только пробелы (`btrim`), а Python-форма — любые пробельные символы (`strip()`: табуляция, перевод строки, неразрывный пробел). Номер «704» с табом или NBSP по краям: Python даёт этаж 7 (звонок — только команде 7-го), SQL — «без этажа» (лента видна всем горничным). Направление безопасное — заявка видна шире, а не теряется, — но «одно правило в двух формах» на таком номере расходится, а набор `ROOMS` в `modules/requests/tests/test_floor_scope.py` таких номеров не содержит. Варианты: `regexp_replace(room, '^\s+|\s+$', '', 'g')` вместо `btrim` или нормализация `room_number` при создании заявки.
