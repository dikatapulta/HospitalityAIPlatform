- [ ] 11.11 — ревью PR #1065 — «Ручные окна основателя делят те же три места» ([QUEUE.md](../QUEUE.md), абзац «Предел три окна») верно только для сторожа: ручные окна занимают его места, но `ops/pool.sh slot` предел не читает и четвёртому-пятому ручному окну номер выдаёт. Уточнить фразу («ручные окна уменьшают место сторожа; сами пределом не ограничены — сколько открыть, решает основатель») или учить `slot` пределу.
