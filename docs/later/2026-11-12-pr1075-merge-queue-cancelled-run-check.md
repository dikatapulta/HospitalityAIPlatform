- [ ] 12.11 — merge PR #1075, окно пула 3 — очередь слияния сняла PR по `check` отменённого прогона. На голову a3e0cb16 GitHub в одну секунду запустил два прогона CI; один отменился (`cancel-in-progress`), но его job `check` с `if: always()` всё равно отработала и записала failure (21:32:10 UTC). `pr_check` в `ops/pool-merge.sh` берёт последний `check` из `statusCheckRollup`, другого ещё не было — и воркер в 21:32:36 снял PR как «красный», хотя живой прогон закончился только в 21:34:45. Здесь живой тоже оказался красным, но зелёный PR снялся бы зря и ждал бы нового окна. Починка — в `pr_check`: `check` из отменённого прогона считать «pending», пока на голове идёт другой прогон. `if: always()` у `check` не трогать: пропущенную job GitHub засчитывает required check как успех.
