- [ ] 14.11 — ревью PR #1155 — `ops/deploy/bootstrap-server.sh`, сверка `sshd -T 2>/dev/null | grep -qi …` под `set -o pipefail`: `grep -q` выходит на первом совпадении, и если `sshd` дописывает вывод (больше 4 КБ — два сброса буфера) уже после этого, он получает SIGPIPE, конвейер возвращает 141 — скрипт печатает ложное «ВНИМАНИЕ: sshd всё ещё принимает пароль». Вход не ломает, только пугает. Починка — `grep -i … >/dev/null` без `-q` или вывод `sshd -T` сначала в переменную.
