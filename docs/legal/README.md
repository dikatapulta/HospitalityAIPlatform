# docs/legal/ — юридический слой (пакет П1, issue #126)

Документы для соответствия Закону РК «О персональных данных и их защите»
№ 94-V (с поправками закона № 231-VIII). Основа — юраудит 22.07.2026
(`docs/audits/2026-07-22-legal-audit-rk.md` и `-recommendations.md`) и ADR-006
(хостинг и резидентность).

## Статус: шаблоны, подготовленные LLM

Тексты **не являются юридической консультацией**. До публикации/подписания:

1. Вставить реквизиты оператора (ИП/ТОО основателя — П4 рекомендаций; без
   юрлица договор с отелем не подписать) — плейсхолдеры вида `[___]`.
   Наименование и email вписаны 21.09.2026: ИП «Alacrity»; для гостей —
   privacy@necturn.com (политика), для отеля — support@necturn.com (договор;
   оба адреса — один ящик Zoho Mail, ADR-006 §2). **ИИН, адрес и ФИО в репозиторий не пишутся** — он
   публичный, а у ИП это личные данные основателя; в шаблонах (DPA, приказ,
   `runbooks/breach-response.md`) они остаются плейсхолдерами и заполняются в
   подписываемых экземплярах вне репозитория.
2. Юридические вопросы решает окно по действующей редакции закона (слово
   основателя 10.11, #947; серия — юрпакет #948): позиции с нормами — записи
   `docs/founder-review/`. Перечень вопросов, что ждали юриста, —
   [`runbooks/founder-actions-pilot-launch.md`](../runbooks/founder-actions-pilot-launch.md) §5.

## Правила сопровождения

- Изменил текст согласия — подними `consent_version` в `channels/common/consent.py`
  тем же PR: согласие перезапрашивается (см. `consent-text.md`, spec 0029 §6).
- Изменил `privacy-policy.md` — это правка ОПУБЛИКОВАННОЙ страницы; выкатывается
  деплоем. Публикуется всё ниже первой строки `---`, выше неё — служебная
  преамбула (гостю не показывается).
- Изменил состав собираемых данных или субоператоров — обнови политику, DPA
  **и** `docs/PII_REGISTRY.md` в том же PR.
- Языковые версии равнозначны по смыслу; расхождение — дефект, эталон при
  правке — русская версия.
