# Тексты согласия на обработку персональных данных (kk/ru/en)

> Пакет П1.3 (issue #126). Требования: явное согласие на обработку (ст. 7–8),
> прямое упоминание трансграничной передачи в страну, не обеспечивающую защиту
> (ст. 16), право возражения против автоматизированной обработки (ст. 19-1),
> ссылка на политику конфиденциальности. Языки — kk/ru/en (Закон «О языках»,
> ЗоЗПП: kk+ru минимум).

## Версия

**`consent_version = "2026-07-28-v1"`**

Правила (юраудит П1.3):

- Текст ниже — единственный источник истины; код каналов (`channels/web`,
  consent-gate Telegram #127) копирует его отсюда и хранит версию рядом с
  фактом согласия (`guest_sessions.consent_version`, для Telegram — аналог).
- **Изменил текст по смыслу → подними версию** (дата-vN) в этом файле и в коде
  тем же PR; гости с прежней версией проходят consent-gate заново.
- Черновик v0 веб-чата заменён текстами этой версии (spec 0029, #127);
  единственная копия в коде — `channels/common/consent.py`, её дословность
  проверяет `tests/test_legal.py`.
- Плейсхолдеры `[ссылка на политику]` / `[саясат сілтемесі]` /
  `[privacy policy URL]` подставляются в рантайме: политику публикует сама
  платформа — `{PUBLIC_BASE_URL}/legal/privacy` (spec 0029 §2). Условие
  «consent-gate не включается без доступной политики» выполнено
  конструктивно: страница есть всегда, отдельного шага публикации нет.

Показ текста — на языке интерфейса гостя; если язык неизвестен (первый
контакт), показываются **все три версии** (kk+ru — законодательный минимум
информации для потребителя, Закон «О языках»/ЗоЗПП; en — демография пилота).
В Telegram язык берётся из клиента гостя (`from.language_code`), иначе — все
три; в веб-чате до входа язык неизвестен всегда, поэтому там показываются все
три. Версии равнозначны; эталон при правках — русская.

## Примечания для реализации (#127, веб-чат) — реализовано, spec 0029

- Без нажатия кнопки LLM не вызывается вовсе (PEP §Gate B п. 4, вариант A) —
  это одновременно юридический gate и защита бюджета от ботов-сканеров.
  В Telegram до согласия не сохраняется и само содержимое сообщений.
- Факт согласия: `consent_at` (UTC) + `consent_version`; хранится как
  доказательная запись и не удаляется по ретеншну сообщений
  (`docs/PII_REGISTRY.md`). Telegram — `conversations`, веб — `guest_sessions`.
- Текст кнопки и полный текст — из этого файла дословно; сокращать полный
  текст в каналах нельзя (упоминание трансграничной передачи и ст. 19-1 —
  обязательные элементы).
