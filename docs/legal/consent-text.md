## Версия

**`consent_version = "2026-07-28-v1"`**

Правила (юраудит П1.3):

- Текст ниже — единственный источник истины; код каналов (`channels/web`,
  consent-gate Telegram #127) копирует его отсюда и хранит версию рядом с
  фактом согласия (`guest_sessions.consent_version`, для Telegram — аналог).
- **Изменил текст по смыслу → подними версию** (дата-vN) в этом файле и в коде
  тем же PR; гости с прежней версией проходят consent-gate заново.
- Черновик v0 веб-чата (`channels/web/page.py`, spec 0027 §3.4) подлежит замене
  на тексты этой версии — код-задача, идёт с #127.
- `[ссылка на политику]` — URL опубликованной `privacy-policy.md` (статическая
  страница на домене платформы); до публикации политики consent-gate не
  включается: согласие без доступной политики неполноценно.

Показ текста — на языке интерфейса гостя; если язык неизвестен (первый контакт),
веб-чат показывает en+ru (демография пилота), Telegram — по языку клиента
гостя, иначе ru. Все три версии равнозначны; эталон при правках — русская.

## Примечания для реализации (#127, веб-чат)

- Без нажатия кнопки LLM не вызывается вовсе (PEP §Gate B п. 4, вариант A) —
  это одновременно юридический gate и защита бюджета от ботов-сканеров.
- Факт согласия: `consent_at` (UTC) + `consent_version`; хранится как
  доказательная запись и не удаляется по ретеншну сообщений
  (`docs/PII_REGISTRY.md`).
- Текст кнопки и полный текст — из этого файла дословно; сокращать полный
  текст в каналах нельзя (упоминание трансграничной передачи и ст. 19-1 —
  обязательные элементы).
