# Рунбук: уведомления персоналу на телефон (веб-пуш)

Как включить уведомления на телефон на контуре, проверить их со своего телефона и
объяснить персоналу. Устройство и решения — [spec 0050](../specs/0050-staff-web-push.md);
секрет — [secrets.md](secrets.md); коды ошибок `ERR-PUSH-*` — [errors.md](errors.md).

Пока на контуре нет ключа, пуша нет совсем: кнопки «Уведомления на телефон» нет,
кабинет зовёт как раньше — звуком и уведомлением открытой вкладки (spec 0039).

## Включить на staging

Делается один раз, после деплоя образа с PR #501. Команды — на сервере
(`ssh deploy@<IP staging>`), из `/opt/hospitality`.

1. Сгенерировать ключ — внутри контейнера, чтобы он не ходил по чатам:
   ```sh
   docker compose -f docker-compose.staging.yml exec app python -m hospitality.tools.generate_vapid_key
   ```
   Первая строка — `STAFF_PUSH_VAPID_PRIVATE_KEY=…`, вторая — публичный ключ для сверки.
2. Сохранить строку с приватным ключом в менеджер паролей основателя («Necturn staging —
   VAPID»). Без копии потеря `.env` обрывает все подписки телефонов.
3. Вписать строку в `/opt/hospitality/.env` (`nano .env`, заменить пустую
   `STAFF_PUSH_VAPID_PRIVATE_KEY=`) и перезапустить процессы:
   ```sh
   docker compose -f docker-compose.staging.yml up -d app worker
   ```
   Негодный ключ — контейнеры не поднимутся, в логе `Конфигурация негодна:
   STAFF_PUSH_VAPID_PRIVATE_KEY …` (значения в логе нет). Вернуть пустую строку и
   повторить шаг 1.
4. Проверить со своего телефона — раздел ниже.

## Проверить со своего телефона

**Android (Chrome):**
1. Открыть кабинет staging в Chrome и войти.
2. Нажать «Уведомления на телефон» → «Разрешить».
3. Появится «Готово — телефон будет звать о новых заявках…» — нажать «Проверить».
4. Заблокировать экран: через несколько секунд придёт «Проверка уведомлений».

**iPhone (iOS 16.4 и новее):**
1. Открыть кабинет в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
2. Открыть кабинет **с иконки** «Кабинет». Попросит войти — код отеля, логин, пароль:
   iPhone может не передать вход из Safari в кабинет с иконки.
3. «Уведомления на телефон» → «Разрешить» → «Проверить», заблокировать экран.

Не пришло — «Уведомление не дошло»: подождать минуту и нажать ещё раз. Не помогает —
лог `staff_push.*` и статьи `ERR-PUSH-002`/`003` в [errors.md](errors.md).

## Что сказать персоналу (инструктаж)

- Уведомления приходят **на этот телефон**, даже когда кабинет закрыт и экран
  заблокирован. Включаются один раз кнопкой «Уведомления на телефон».
- **iPhone** — только кабинет с иконки на экране «Домой» (шаги выше); в Safari
  уведомлений нет, кабинет сам подскажет, как добавить иконку.
- **Android** — Chrome. Если уведомления опаздывают, в настройках телефона снять
  экономию батареи для Chrome (на Xiaomi, Huawei и Samsung она усыпляет приложения).
- Режим «Не беспокоить» и беззвучный режим глушат и эти уведомления.
- **«Выйти» в кабинете на телефоне — телефон перестаёт звать.** Ушли со смены —
  выйдите; пришли — войдите, и уведомления вернутся сами.
- Телефон зовёт только о заявках **своих служб** (и ресепшен — о тех, что никто не
  взял): тех же, о которых звучит кабинет на компьютере (spec 0045 §4).

## Гостевая копия — только по слову основателя

На копии ключ не заводится, пока не выполнено всё:

1. Слово основателя.
2. **Письмо отелю за 10 рабочих дней** (п. 4.4.4 пилотного договора): в перечне
   получателей появляются службы пуша Google и Apple — они получают зашифрованные
   уведомления персоналу (номер заявки, номер комнаты, служба; прочитать их может
   только телефон работника, текста гостя и имени нет); и новая категория данных
   работников к п. 4.2.5 — адрес подписки телефона. Отель вправе не согласиться.
3. Смержен PR рассылки (PR 2 spec 0050 §10): без него телефон получает только проверку.
4. Ключ копии — **свой**, шаги «Включить на staging» в каталоге копии
   `/home/deploy/hospitality-pilot` с её compose-файлом ([pilot-copy.md](pilot-copy.md)).

## Сменить ключ

Новый ключ — шаги 1–3 «Включить на staging». Все подписки обрываются: телефон
переподписывается сам, когда сотрудник откроет кабинет. Утечка ключа — сменить
сразу: с ключом и адресами подписок из базы можно слать уведомления персоналу.
