# Spec 0066: вид гостевого чата — цвет подложки, узор и знак отеля выбирает менеджер

- **Статус:** принята сессией; спека и код — один PR (#776)
- **Issue:** #761
- **Дата:** 2026-11-03
- **Решение основателя:** 03.11 через окно-консультанта — «в кабинете можно было настраивать дизайн
  немного — типа обои поменять» (тело issue); по умолчанию — «Небо и золото» и обои «Алматы»
  с заметностью 60 % (решения в #746, обои картинкой — #773).
- **Меняет:** [spec 0047](0047-file-storage.md) §4 — новое назначение файла `hotel_logo` (§4).

## 1. Проблема

Вид гостевого чата (#746) задан кодом: подложка «Небо и золото», обои «Алматы» (#773), в кружке шапки — первая
буква названия отеля. Вид чата — лицо отеля; второму отелю пришлось бы менять код (NG-7).

## 2. Решение — немного, не конструктор

Раздел кабинета «Вид гостевого чата» (группа «Управление», только менеджер — docs/RBAC.md):

1. **Цвет подложки** — один из готовых вариантов, а не любой цвет: «Небо и золото» (`sky_gold`,
   умолчание), «Изумруд» (`emerald`), «Горы на закате» (`sunset`). Вариант меняет только
   подложку — градиент днём и ночью; картинка обоев берёт цвет из него (`mix-blend-mode:
   luminosity`, #773), поэтому перекрашивается вместе с ним. Пузыри сообщений, кнопки и стеклянные плашки
   общие: контраст текста не зависит от выбора, а новый вариант не требует новой проверки
   контраста — только подбора пастельной подложки.
2. **Узор** — заметность рисунка обоев: «Выключен» / «Тише» / «Обычный» / «Ярче» (`off` /
   `quiet` / `normal` / `bright`) — множитель 0 / 0,6 / 1 / 1,5 к умолчанию 60 %, то есть 0 / 36 /
   60 / 90 %. «Выключен» — один градиент, картинка не показывается.
3. **Знак отеля в шапке** — картинка PNG, JPEG или WebP; SVG — нет (в нём бывает скрипт). Не
   квадрат — кружок обрезает по центру. Нет знака — первая буква названия, как сейчас. Знак
   стоит в шапке, у ответов отеля и во вкладке браузера (favicon).
4. **Предпросмотр** рядом с настройками: два телефона — «Днём» и «Ночью» — с примером переписки.
   Цвет и узор меняют предпросмотр сразу, в БД — по «Сохранить». Знак загружается сразу.

Не делать: свои цвета пипеткой, свои обои картинкой отеля, шрифты, вид кабинета — «потом», по
запросу отеля.

## 3. Хранение — конфиг тенанта

`TenantConfig.guest_chat_look: GuestChatLook` — `palette`, `pattern`, `logo_file_id` (id строки
`uploaded_files` или `None`). Поле аддитивное → `schema_version` остаётся 1 (§6 FOUNDATION).
Источник — кабинет, не файл профиля: `tools/onboard_tenant.build_config` переносит прежнее
значение, иначе повторный онбординг сотрёт выбор. Правка — только `mutate_tenant_config`.

Цвета вариантов — `channels/web/look.py` (владелец), ключи вариантов — `Literal` в схеме
конфига. Умолчание «Небо и золото» одновременно объявлено в `assets/chat.css`; тест держит их
равными.

## 4. Знак отеля — файл узла (spec 0047)

Новое назначение `hotel_logo`: только картинка, перекодировка в WebP не больше 256 px (кружок
44 px, три пикселя на точку экрана), без метаданных, шифрование — как у всех. Срок — пока знак
стоит в настройках: замена удаляет прежний файл после записи новой ссылки, «Убрать» — ссылку и
файл (порядок и тихое удаление — канон `room_service/photos.py`). Не удалился прежний файл —
WARNING, потеряно место на томе, а не данные.

Выдача гостю — `GET /g/{slug}/logo/{file_id}` без сессии: шапка со знаком видна до входа, как
и название отеля. Отдаётся **только файл, который сейчас стоит знаком отеля**; любой другой id
(фото блюда, документ гостя, прежний знак) — 404 `ERR-FILES-004`, как несуществующий. Адрес —
id файла: замена меняет адрес, кэш браузера (`file_response`, час) старый знак не покажет.

## 5. Гостевая страница

Чат и страница привязки с листка (spec 0033 §6) читают `guest_chat_look` при каждом открытии —
новый вид гость видит со следующего открытия, без перезапуска сервера.

- Умолчание (`sky_gold` + `normal`, без знака) не добавляет к странице ни байта: условие веса
  #746 (не тяжелее вдвое) проверяется на ней.
- Другой вариант — блок `:root { --wall-… }` для дня и ночи после стилей чата; другой узор —
  правило заметности картинки обоев.
- Знак — `<img>` в кружке шапки и правило его обрезки; ответы отеля копируют кружок шапки
  (`chat.js`), без знака — букву, как раньше.

Конфига нет (онбординг не завершён) — умолчание.

## 6. Кабинет

- Страница `GET /staff/{slug}/chat-look` — канон `_page_context`, роль `manager`.
- `POST /staff/{slug}/api/chat-look` — `{palette, pattern}`, JSON-щит CSRF; неизвестное значение
  — 422 схемы.
- `POST /staff/{slug}/api/chat-look/logo` — `multipart/form-data`, одно поле `logo`; щит загрузки
  и `read_upload_form` (канон spec 0047) — после права. Отказы файла — ERR-FILES-001…003 текстом
  узла.
- `POST /staff/{slug}/api/chat-look/logo/remove` — «Убрать».
- `GET /staff/{slug}/api/chat-look/preview?palette&pattern&theme=day|night` — телефон
  предпросмотра в iframe: **сама страница гостя** (`web.page.render_preview`) с лентой-образцом,
  без скрипта (обои — сразу, а не после `load`); ночь и день — подменой медиазапроса тёмной темы. Так в кабинете нет копии цветов
  чата, и предпросмотр не разойдётся с тем, что увидит гость. Свои заголовки: стили встроенные,
  картинки — свои и `data:` (буква во вкладке), скрипты закрыты, встраивать — только своим страницам
  (`frame-ancestors 'self'`); CSP кабинета встроенных стилей и `data:` не пускает.

Страница без inline-стилей и без своих цветов чата. Логи: `staff.guest_chat_look_changed`
(вариант, узор, `user_id`), `staff.guest_chat_logo_set` / `_removed` (`file_id`, `user_id`);
файлы — метрики узла.

## 8. Тесты

- Схема: умолчание, неизвестный вариант — отказ; онбординг переносит выбор и знак.
- Страница чата: умолчание — байт в байт прежняя; вариант — свой блок `:root`, узор — правило
  картинки; знак —
  `<img>` и favicon по адресу; страница листка — тот же знак.
- Выдача знака: свой — 200 и картинка; чужой id, фото блюда, прежний знак после замены — 404.
- Кабинет: не менеджер — «нет доступа» и 403; сохранение пишет конфиг; загрузка ставит знак и
  удаляет прежний файл; «Убрать» снимает знак и файл; SVG — ERR-FILES-002; предпросмотр — без
  скрипта, тема принудительно, заголовки встраивания.
- Умолчание `look.py` равно объявленному в `chat.css`.
