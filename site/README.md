# site/ — публичная страница necturn.com

Одна статическая страница о продукте для тех, кто заходит на корень домена: отель,
его юрист, гость, увидевший `staging.necturn.com` в адресе чата. Решение — где живёт
код, почему без сборки и где хостится — [ADR-019](../docs/adr/ADR-019-public-site-static-pages.md);
выкладка и проверка после неё — [docs/runbooks/public-site.md](../docs/runbooks/public-site.md).

## Файлы

| Файл | Что даёт |
| --- | --- |
| `index.html` | Вся страница: стили, разметка, переводы и скрипт в одном файле, без сборки и зависимостей |
| `_headers` | Заголовки ответа Cloudflare Pages: CSP без внешних источников, запрет встраивания в чужие сайты |

## Как устроены языки

Три языка — kk, ru, en; язык выбирается по `?lang=kk` в адресе, без него — по языку
браузера (незнакомый язык → английский). В браузере ничего не хранится.

- **Русский** — сама разметка: элемент с `data-i18n="ключ"` (текст) или
  `data-i18n-attr="атрибут:ключ"` (например, `aria-label`). Без JavaScript
  страница показывается по-русски.
- **Казахский и английский** — JSON-блок `<script id="i18n">` в конце файла, по тем же ключам.
- Новый текст = элемент с новым ключом в разметке + строка с этим ключом в `kk` и `en`.
  Забытый перевод ловит `tests/test_site.py` (`make check`).

## Инварианты — не ломать

- **Ничего не загружается извне**: ни шрифтов с CDN, ни счётчиков, ни картинок по ссылке.
  Шрифты системные, иконки — встроенный SVG. Подвал обещает «нет cookies, трекеров и
  аналитики»; это стерегут `tests/test_site.py` и CSP в `_headers`. Форма, аналитика или
  cookie на странице — это обработка данных посетителей, и сначала нужен новый ADR (ADR-019).
- **Никаких реквизитов, кроме наименования** «ИП «Alacrity»»: ИИН, адрес и телефон ИП —
  личные данные основателя, репозиторий публичный.
- **Не называть отели-клиентов**, не писать отзывов, цифр эффективности и цен.
- **Факты о продукте — по коду и спекам.** Сейчас на странице нет приёма заявок: в пилоте
  он выключен флагом `ENABLE_SERVICE_REQUESTS` (`src/hospitality/ai/README.md`).
  Число «90 дней» на странице не пишется: его владелец —
  [spec 0032](../docs/specs/0032-guest-text-retention.md) и политика.

## Типовые правки

- **Контакт.** Сейчас вместо почты плейсхолдер (`contact.placeholder`, комментарий
  «ЗАМЕНИТЬ» в разметке). Когда почта появится: заменить плейсхолдер ссылкой
  `mailto:` во всех трёх языках и выключить в Cloudflare «Email Address Obfuscation» —
  иначе Cloudflare подменит адрес скриптом, который CSP страницы заблокирует
  (рунбук, §4).
- **Политика конфиденциальности** публикуется приложением на staging (spec 0029);
  когда она переедет, поправить обе ссылки на неё (раздел «Гостям» и подвал).
- **Посмотреть локально** — открыть `site/index.html` в браузере двойным щелчком; язык —
  `index.html?lang=kk`.
