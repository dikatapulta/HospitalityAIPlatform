# integrations/exchange_rates — адаптеры официальных курсов валют

Реализации порта `ExchangeRatesPort` (`shared/ports/exchange_rates.py`,
[spec 0084](../../../../docs/specs/0084-concierge-weather-and-rates.md)). Подключает только
composition root — `build_exchange_rates(settings)` и `set_exchange_rates` (`app.py`); ядро
и модули адаптеры не импортируют (контракт 2 import-linter).

## Что умеет

`official_rates(on) -> OfficialRates` — курсы к тенге, действующие в день `on`: на эту дату,
иначе последние за 3 предыдущих дня; `check()` — отвечает ли банк. Курса нет —
`ExchangeRatesUnavailableError`. Число — как опубликовано: тенге за `units` единиц.

| Адаптер | Файл | Для чего |
|---|---|---|
| `FakeExchangeRatesAdapter` | `fake.py` | тесты, CI, локальный uvicorn (ADR-007): пока ничего не опубликовано — круглые `DEFAULT_RATES` на любой день; после `publish` — как банк, только опубликованные даты; `unavailable = True` — банк лежит |
| `NbkExchangeRatesAdapter` | `nbk.py` | контуры: Национальный банк РК, `get_rates.cfm?fdate=ДД.ММ.ГГГГ` |

## Источник (сверен 11.11.2026)

- Адрес и формат — [nationalbank.kz/ru/page/RSS](https://nationalbank.kz/ru/page/RSS): только
  https; XML `<rates>` с `<date>` и `<item>` на валюту — `title` (код ISO 4217),
  `description` (тенге), `quant` (за сколько единиц: KRW и UZS — за 100). Около 50 валют.
- Курс складывается на KASE в 15:30 по Астане и действует со следующего дня; на выходные он
  тоже есть. На дату, курс которой ещё не установлен, ответ без `<item>`.
- Условия — [«Об использовании данных»](https://www.nationalbank.kz/ru/page/data-usage-terms):
  свободно и бесплатно, в том числе в программах; распространение — со ссылкой на источник.
  Бот называет курс «официальным курсом Национального банка РК» (spec 0084 §4).

## Кэш, отказы, лимиты

- Курс на саму дату окончателен — копия живёт до перезапуска процесса (старше недели
  выбрасывается). Курс предыдущего дня — 10 минут: свежий мог выйти.
- Таймаут — 3 с на весь поиск по дням (`asyncio.timeout`; таймаут `httpx` — на фазу запроса,
  капающий ответ его не будит). Нет ответа — поиск обрывается сразу, гость не ждёт четырёх
  таймаутов. Ответ больше 512 КБ — отказ.
- Отказ — ERR-CONCIERGE-002: пауза 60 с, прежняя копия на эту дату отдаётся, если есть.
- Строка одной валюты не по формату пропускается с WARNING `exchange_rate_item_skipped`;
  не осталось ни одной, дата ответа не та, валюта дважды — отказ.

## Health и метрики

- `check()` — запрос курса на сегодня (UTC) → 200; Fake — `not unavailable`. В
  `/health/ready` не входит: без курса консьерж работает (FOUNDATION §8 правило 2).
- `concierge_source_calls_total{source="exchange_rates", outcome}`: `ok` — запрос, на который
  банк ответил (и пустым «курса ещё нет»); `error` — отказ или курса нет ни на один день
  поиска. Ответ из копии не считается.

## Тесты

Один контрактный набор на оба адаптера — `tests/test_exchange_rates_port.py` (R-7): адаптер
банка говорит с `httpx.MockTransport`, который отвечает XML из состояния Fake, — курсы
обязаны совпасть. Там же — формат даты, кэш, обрыв поиска, пауза и строки не по формату.
