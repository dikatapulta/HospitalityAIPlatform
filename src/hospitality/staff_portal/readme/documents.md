# staff_portal · Документы для АВР

Часть паспорта кабинета персонала (R-4, #891): страница «Документы для АВР» и «Скачать для 1С». Общее устройство, вход и безопасность, события, таблицы и общие файлы — [README.md](../README.md). Правка раздела обновляет этот файл тем же PR.

## Маршруты

- `GET /staff/{tenant_slug}/act-requests` — «Документы для АВР» (query `from`, `to` —
  дни отеля, `status=to_check|checked`; служба «Бухгалтерия», ресепшен, менеджер —
  `act_requests.can_handle_act_requests`, остальным 403 «Нет доступа»; выключатель
  `ENABLE_GUEST_DOCUMENTS` прячет только пункт меню), `GET …/act-requests/{id}/files/{file_id}`
  — файл этого запроса (`platform.files.file_response`: PDF и DOCX вложением,
  `no-store`; чужой — 404 `ERR-DOCUMENTS-004`), `GET …/act-requests/export` — «Скачать для 1С»
  ([spec 0052](../../../../docs/specs/0052-act-requisites-1c-export.md): Excel со строками
  «Проверено» за `from`–`to`, вложением, `no-store`; строк нет или больше 1000 — 303 на
  страницу с `export=empty|too_many`), `POST …/api/act-requests/{id}/requisites|checked`
  — правка полей и «Проверено» (то же право, отказ — 403 `ERR-AUTH-003`)
- При `ENABLE_WORK_COMPLETION_ACTS` ([spec 0086](../../../../docs/specs/0086-work-completion-act-draft.md)
  §3; без флага — 404): `POST …/api/act-requests/{id}/acts` — черновик АВР (JSON
  `WorkCompletionActCreate`, `Origin` — как у правки, то же право), `GET
  …/act-requests/acts/{act_id}.xlsx` — файл акта вложением, `no-store`; чужой или обезличенный
  — 404 `ERR-DOCUMENTS-004`
