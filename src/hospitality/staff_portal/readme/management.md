# staff_portal · Главная и управление

Часть паспорта кабинета персонала (R-4, #891): главная, сводка дня, журнал изменений, статистика, справочник отеля, вид гостевого чата и «Сотрудники». Общее устройство, вход и безопасность, события, таблицы и общие файлы — [README.md](../README.md). Правка раздела обновляет этот файл тем же PR.

## Маршруты

- `GET /staff/{tenant_slug}/summary` — сводка дня (senior — числа своих служб без
  эскалаций, или manager, spec 0045 §3; query:
  `day=today|yesterday`, непонятное значение — «сегодня»)
- `GET /staff/{tenant_slug}/changes` — журнал изменений (senior — строки своих
  служб, или manager; query:
  `day=ГГГГ-ММ-ДД`, `login`, `action`, `offset`; непонятное значение —
  умолчание)
- `GET /staff/{tenant_slug}/stats` — статистика по сотрудникам (senior — итоги
  своих служб, или manager, spec 0065 §2.3; query: `period=today|7d|30d`,
  непонятное значение — «7 дней»; `ENABLE_STAFF_STATS` выключен — 404)
- `GET /staff/{tenant_slug}/knowledge` — справочник отеля (роль manager)
- `POST /staff/{tenant_slug}/api/knowledge/facts`, `…/facts/update`,
  `…/facts/delete` — JSON-действия справочника (роль manager; тема — в теле, а не
  в пути: «/» в пути даёт 404 даже процентно-кодированным; отказ — `ERR-PLATFORM-009`)
- `GET /staff/{tenant_slug}/chat-look` — вид гостевого чата (роль manager, spec 0066)
- `POST /staff/{tenant_slug}/api/chat-look`, `…/chat-look/logo`, `…/chat-look/logo/remove`,
  `GET …/api/chat-look/preview` — его действия и телефон предпросмотра (роль manager)
- `GET /staff/{tenant_slug}/team` — сотрудники (роль manager)
- `POST /staff/{tenant_slug}/api/team/invites`, `…/team/invites/{id}/reissue`
  («Новая ссылка», spec 0037 §4), `…/team/invites/{id}/revoke`,
  `…/team/members/{id}/access` (уровень и службы одним телом, `ERR-AUTH-015` —
  spec 0045 §6), `…/team/members/{id}/deactivate`,
  `…/team/members/{id}/password-reset` (сотруднику и старшему; менеджеру — только
  суперадмин, решает `staff_superadmin.issue_password_reset`, #944) —
  JSON-действия состава (роль manager)
- `POST /staff/{tenant_slug}/api/team/invites/batch` — приглашения списком и лист для
  печати (роль manager, spec 0072 §4; `team_invites_api.py`)
- `POST /staff/{tenant_slug}/api/team/members/{id}/erase` — JSON-действие
  суперадмина (роль manager + `is_platform_admin`,
  `staff_superadmin.require_superadmin`, spec 0044)
