# staff_portal · «Служебные записки»

Часть паспорта кабинета персонала (R-4, #891): раздел «Служебные записки» ([spec 0077](../../../../docs/specs/0077-staff-memos.md), #936) и плашка о привязке устройства подписи на каждой странице отеля. Общее устройство, вход и безопасность — [README.md](../README.md). Правка раздела обновляет этот файл тем же PR.

Серия §11: PR 4б-1 (этот файл впервые) — «Моя подпись», плашка и «Сбросить подпись»; PR 4б-2 — записки: вкладки «Ждут меня», «Мои», «Все», черновик, карточка с листом подписей, окно подтверждения, пуши, число «Ждут меня» в меню; PR 4б-3 — печать отправленной записки и поиск с фильтрами по реестру; PR 5б — объяснительные: «Затребовать объяснение» с фото, страница требования с «Получил(а)» и сроком, черновик и карточка объяснительной, «Дополнить», требования во вкладках и в числе «Ждут меня». Данные и подтверждение — модуль `modules/memos` и `platform/staff_confirm`, `staff_passkey_binding`, `staff_passkey_notice`, `staff_passkey_history`.

## Маршруты

- `GET /staff/{tenant_slug}/memos`, `…/memos/waiting|mine|all|signature` — вкладки (при `TenantConfig.memos_enabled`, иначе 404 у страниц и действий; любой уровень).
- `GET …/memos/waiting|mine|all?q=&who=&kind=&status=&since=&until=` — поиск и фильтры по своим записям вкладки (§5).
- `GET …/memos/new`, `…/memos/{id}`, `…/memos/{id}/edit`, `…/memos/{id}/print` — черновик, карточка (только участнику: черновик — автору; чужая — ERR-MEMO-001, 404), правка своего черновика (записки или объяснительной — по виду), печать отправленной (открытие — строка журнала просмотров).
- `GET …/memos/explanations/new[?demand={id}]`, `…/memos/{id}/supplement` — новая объяснительная (по требованию — только сотруднику после «Получил(а)», иначе 404) и «Дополнить» своей поданной; `…/memos/demands/new` — «Затребовать объяснение» (`senior`, `manager`; иначе 404), `…/memos/demands/{id}` и `…/memos/demands/{id}/photo` — требование и его фото (затребовавшему и сотруднику; фото — `file_response`, `no-store`, открытие — лог `staff.memo_demand_photo_read` с id).
- `POST …/api/memos/demands` (multipart), `…/demands/{id}/begin|complete` — требование и «Получил(а)»; отказы — ERR-AUTH-003 (403, не `senior`/`manager` или суперадмин), ERR-PLATFORM-002 (422: `employee_id`, `not_a_member`, `not_your_service`), ERR-FILES-001…003, -005, -006, у «Получил(а)» — как у действий записок ниже.
- `POST …/api/memos/drafts|explanations|{id}/draft|{id}/explanation|{id}/supplement|{id}/withdraw|{id}/submit|{id}/based-on|{id}/begin|{id}/complete` — JSON-действия записок; отказы — ERR-MEMO-001 (404), -002 (409, запись уже изменилась), -003 (409, нет образца подписи), ERR-AUTH-017 (`password`, `expired`, `invalid`, `unknown_key`), ERR-AUTH-006, ERR-PLATFORM-002 (422: форма, `not_a_member`, `not_senior_or_manager`).
- `POST …/api/memos/signature/bind/begin|bind/finish|devices/{id}/revoke|sample` — JSON-действия «Моей подписи»; отказы — ERR-AUTH-017 (пароль), ERR-AUTH-006 (бюджет попыток входа), ERR-AUTH-018 (привязка: `not_remembered`, `platform_admin`, `limit`, `already_bound`, `invalid`, `expired`).
- `POST …/api/passkey-notice/{id}/ack|disown` — плашка о привязке (любой уровень, без флага раздела).
- `POST …/api/team/members/{user_id}/signature-reset` — «Сбросить подпись» (менеджер, при флаге раздела).

## Безопасность

- Привязка — только во входе с «Запомнить меня» и не суперадмину; страница говорит это заранее, сервер отказывает сам (`staff_passkey_binding`).
- Пароль во всех трёх местах (привязка, отвязка, «Это не я») — под бюджетами входа (`staff_passkeys.require_password`).
- Плашку видят и закрывают только другие входы владельца; привязавший вход её не видит (`staff_passkey_notice.unseen_bindings`).
- Кто вправе действие записки и в каком статусе — модуль `memos` при каждом вызове; кнопки карточки — только подсказка. Подтверждение — `staff_confirm`: вызов одноразовый, 5 минут, только начавшей сессии и того же действия; пароль — под бюджетами входа.
- Пуш — без заголовка, текста и решения записки: его видно на заблокированном экране.
- В логах — только id (события платформы `staff.passkey_*`, `staff.confirmation_*`, модуля `memo_*`, `memo_push_sent`); пароля, названия устройства, заголовков и текстов в логах маршрутов нет.
