# staff_portal · Очередь заявок, сигнал и уведомления

Часть паспорта кабинета персонала (R-4, #891): очередь заявок, «Новая заявка», «Отправленные», «Диалоги», сигнал кабинета и уведомления на телефон. Общее устройство, вход и безопасность, события, таблицы и общие файлы — [README.md](../README.md). Правка раздела обновляет этот файл тем же PR.

## Маршруты

- `GET /staff/{tenant_slug}/requests` (+`/fragment`) — очередь (роль любая,
  query: `tab=open|closed|week`, `category`, `mine=1`, `q` — комната или `#N`, `created=N&service=<id службы>` —
  плашка о только что созданной заявке; видны заявки своих служб, у ресепшена и
  менеджера — все, `category` чужой службы — 403 «Нет доступа», у fragment — 403
  без тела, spec 0045 §5)
- `GET /staff/{tenant_slug}/requests/new` — форма ручного приёма (роль любая)
- `GET /staff/{tenant_slug}/requests/new/fields` — фрагмент полей окна «Новая заявка» (роль любая, #636)
- `POST /staff/{tenant_slug}/api/requests` — создать заявку вручную (роль любая;
  три поля, `origin=staff_manual`)
- `POST /staff/{tenant_slug}/api/requests/{id}/claim|complete|cancel|requeue|transfer` —
  JSON-действия очереди (роль любая; `cancel` требует `reason` из списка
  spec 0057 — `by_guest` 422, у `other` обязателен `note`, у прочих он
  отбрасывается; страница «Документы для АВР» шлёт `other` со своим текстом; `transfer` —
  `category_id` службы; `requeue` возвращает взятую в очередь — spec 0042; заявка
  не из служб сотрудника — 403 `ERR-REQUESTS-007`, spec 0045 §5; `complete` —
  необязательные `note` и `remainder`: `remainder: true` с примечанием заводит остаток
  в очереди службы (`requests_api.complete_with_remainder`, spec 0079 §2.3), без
  примечания — 422; ответ — заявка и `remainder_daily_number` остатка или `null`)
- `GET /staff/{tenant_slug}/api/requests/signal` — невзятые заявки для сигнала
  кабинета (роль любая, адресаты — по лестнице spec 0045 §4; без сессии — 401
  конвертом, не редирект) и номера доски выездов (`turnovers`, spec 0046 §7);
  запертая короткая сессия проходит фоновым чтением, `session` — её состояние
  (spec 0073)
- `POST /staff/{tenant_slug}/api/push/subscriptions`, `…/push/subscriptions/delete`,
  `…/push/test` — уведомления на телефон (любой уровень, spec 0050)
- `GET /staff/sw.js` — service worker веб-пуша (БЕЗ сессии: статичный файл)
