# staff_portal · Товары и меню, заказы, столики

Часть паспорта кабинета персонала (R-4, #891): панель «Товары и меню», карточки заказа в номер и запроса столика. Общее устройство, вход и безопасность, события, таблицы и общие файлы — [README.md](../README.md). Правка раздела обновляет этот файл тем же PR.
