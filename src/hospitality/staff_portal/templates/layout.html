{# Каркас страницы кабинета (spec 0033 §4, ADR-014; CANONICAL). Страницы наследуют его: block title/brand/content. shell — каркас страниц отеля (issue #462, макет staff-dashboard-v2; кладёт только router._hotel_page, контекст — shell.shell_context): боковое меню по роли, карточка «имя · роль · выйти», верхняя полоса с неактивными кнопками будущего (поиск, тема, колокольчик — disabled, подпись «скоро»). Без shell — простая шапка: block brand, display_name включает блок «кто вошёл + Выйти»; show_logout — кнопка «Выйти» без имени (403-страница: сессия жива, членства нет).
